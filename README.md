# Female autism discourse: Reddit (BTM) vs. scientific literature (LDA)

Code for the Master's Thesis **"The Other Side of The Spectrum: A Topic Modelling Comparison of Online Community Discourse and Scientific Literature on Female Autism"**, Universidad Carlos III de Madrid, 2026.
Author: José Manuel Eyzaguirre Venegas.

## 1. What this is

Two **independent** topic-modelling pipelines, one per corpus, both covering January 2025 to May 2026. Each one runs on its own, in its own folder.

| | `reddit/` | `scientific/` |
|---|---|---|
| Source | Posts from r/AutismInWomen (Arctic Shift API) | 17 peer-reviewed papers found on PubMed |
| Size | 68,788 posts scraped, 57,070 with text, 57,041 modelled | 17 papers, 16 modelled (paper 10 is a commentary and is excluded) |
| Model | BTM (Biterm Topic Model), suited to short texts | LDA, suited to long texts |
| Number of topics | k = 6, chosen by qualitative comparison of topics | k = 6, chosen by qualitative comparison of topics |

## 2. Repository structure

```
reddit/       scrape_code.R + step1 to step4 (.Rmd)
scientific/   step1 to step4 (.Rmd) + .here
```

Run the steps in numeric order. Each one reads the files written by the previous one.

| Step | `reddit/` | `scientific/` |
|---|---|---|
| scrape | `scrape_code.R`: downloads the posts (fixed dates, monthly pagination) | (PDFs obtained manually, see section 5) |
| 1 | EDA and filter to posts with text | PDF text extraction, column reordering, cleaning, exclusion of paper 10 |
| 2 | Pseudonymisation, lemmatisation (udpipe), POS filter, stopwords | Lemmatisation (udpipe), POS filter, stopwords |
| 3 | Vocabulary pruning, BTM fits, choice of k, domain stopwords, final model | Document-term matrix, cleaning, LDA for k = 2 to 10, choice of k |
| 4 | Interpretation: top terms, flair check, topic labels | Interpretation: top terms, topic membership per paper, topic labels |

## 3. Data: what is and is not in this repository

| Included | Not included |
|---|---|
| All code | Reddit posts: text, titles, authors, links |
| **Tokenised inputs**, lemmas only (see below) | The 17 PDFs and the text extracted from them |
| Final models and result tables | Files that contain running text, such as `annotation_*.rds` (they hold full sentences) |
| `reddit/outputs/tables/id_flair.csv` (post id and flair, no text) | Figures, HTML reports and models for each k (all regenerated by running the code) |

**Tokenised inputs that are shared**

| File | Content |
|---|---|
| `reddit/tokens_clean_lemmatized.csv` | Post id and lemma |
| `reddit/btm_data_v2.rds` | Final BTM input: post id and lemma, in order |
| `scientific/tokens_clean_lemmatized_literature.csv` | Paper number and lemma |
| `scientific/dtm_literatura_final.rds` | Word counts per paper, without word order |

They contain only lemmas of content words (nouns, verbs, adjectives, adverbs, proper nouns), with no punctuation, function words or author information. Sharing them was agreed with the thesis supervisor.

**Why the rest is not shared**
- **Reddit posts**
  - Reddit's terms restrict redistributing user content.
  - Posts contain self-disclosed health information (a special category under GDPR, Art. 9), and full texts are easy to re-identify by searching for a phrase.
  - Users can delete their posts, and shared raw text would ignore that.
  - Usernames were never shared: they are replaced by a hash inside the session and never exported. (An unsalted hash is pseudonymisation, not full anonymisation.)
- **Papers:** the PDFs and their text are protected by publisher copyright. Only the list of papers is shared (`scientific/data/ids/corpus_papers.csv`: paper number, title, authors), created by `scientific/step1`.

## 4. Requirements

- R 4.5.1 (the version used). RStudio is recommended.
- Internet access: Arctic Shift API, and the udpipe model, which is downloaded automatically (`english-ewt-ud-2.5-191206`, about 16 MB).

```r
install.packages(c(
  "tidyverse", "tidytext", "jsonlite", "lubridate", "digest",   # both / scraping
  "udpipe", "BTM", "topicdoc", "kableExtra",                    # reddit
  "pdftools", "here", "topicmodels"                             # scientific
))
```

Package versions are not pinned. BTM 0.3.8 was used.

## 5. How to reproduce

Knit each `.Rmd` from RStudio. R uses the folder of the `.Rmd` as working directory, and the `data/` and `outputs/` folders are created there.

### A. Interpretation only (fast, works with this repository as it is)
Knit `reddit/step4_analysis_btm_reddit.Rmd` and `scientific/step4_LDA_final_analysis.Rmd`. They read only the final models and tables that are included, and they need no raw data.

### B. Full replication from raw data
- **Reddit:** run `reddit/scrape_code.R` from inside `reddit/`, then knit `step1` to `step4` in order.
- **Scientific:** put the 17 PDFs in `scientific/official_cientific_corpus/`, then knit `step1` to `step4` in order.
  - Get the PDFs through PubMed or your institution, using the list in `corpus_papers.csv`.
  - Each file name must **start with the paper number** (for example `1.-....pdf`).
  - The `scientific/.here` file makes that folder the project root.
  - Papers were identified by a manual PubMed search (autism plus gender-related terms). [Add the exact query and the date.]

Approximate runtime on the machine used: `scientific/` takes minutes; `reddit/step2` takes up to about 85 minutes; `reddit/step3` takes about 5 hours (12 BTM models, 20 to 37 minutes each). Fitted models and annotations are saved to disk and reloaded on later runs. To recompute the annotation, delete `annotation_reddit.rds` or `annotation_literatura.rds`.

### C. Refit the models from the tokenised inputs (partial)
- **Reddit:** `step3` starts from `tokens_clean_lemmatized.csv`, so the fits and the choice of k can be rerun. The chunks that read `reddit_filtered.csv` (raw posts) cannot: the flair checks (9.2 to 9.5), 17.2, 17.4 and Step 18.
- **Scientific:** load `dtm_literatura_final.rds` (`dtm <- readRDS(...)`) and run the chunks of Step 2 of `step3` to refit LDA. The cleaning in Step 1 of `step3` needs `annotation_literatura.rds`, which comes from the PDFs.

## 6. Reproducibility notes

- **Seeds:** BTM uses `set.seed(1234)` before each fit; LDA takes its seed through `control = list(seed = 123)`. Repeated runs on the same machine gave identical results. Exact equality across operating systems is not guaranteed for BTM, which is why the final model is saved.
- **Reddit data change over time.** Re-scraping will not return exactly 68,788 posts, because posts are deleted or moderated. The dates are fixed (`2025-01-01` to `2026-05-29`) so the period is the same.
- **`topicdoc:::coherence`** is an internal function of the package and may change between versions.
